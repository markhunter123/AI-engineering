re-43-five-containers	"A filled blue square is a fact the container stores, a hollow square is a fact it has lost. Blue rows are control-flow instructions: jumps and a table in native code and CIL, compare-and-jump pairs in CPython, tableswitch in the JVM, nested blocks and br_table in WebAssembly. Amber rows carry a variable name inside the instruction itself, which only the CPython listing does."
